# Statistically Certified Autonomy: reproducibility repository

Code, data and paper sources for **"Statistically Certified Autonomy: Design Principles for Risk-Bounded Delegation to AI Agents"**, a Completed Research Paper prepared for ECIS 2027 (deadline 30 October 2026).

The paper designs a delegation gate that decides, for every tool call an AI agent proposes, whether the call runs autonomously, goes to a human or is blocked. The gate wraps three commercial decision models (jev, microsoft, gpt, accessed through the OpenRouter decisions endpoint) with conformal calibration and states a statistical guarantee on harmful autonomous executions. All results come from scoring 1,433 calls of the SAFETY SENTRY test split.

**Status:** the paper (version 5, 16 pages) is reproducible from this repository. The confirmatory evaluation on untouched data is planned and frozen in `confirmatory/`, but not yet run.

## Repository map

```
data/scores/            decision-model scores of the original run (test split) and the pilot run
notebooks/              the original notebooks 01 to 03, their Markdown exports and EXPERIMENTS.md
analysis/               steps 01 to 10 that produce every number in the paper; run_all.sh runs them in order
analysis/archive/       an early prototype of the certified policy, superseded by step 03
results/                outputs of analysis/ (JSON, CSV, logs); regenerated by run_all.sh
figures/                make_figs.py and Figures 1 to 7 of the paper
paper/                  manuscript.md (the paper's source), build scripts, ECIS template, build/ with DOCX and PDF
confirmatory/           frozen protocol, scoring script for the new runs, frozen analysis, student instructions
docs/                   changelog, responses to the internal reviews, analysis notes, the review texts
```

## Reproduce the paper

```bash
pip install -r requirements.txt
bash analysis/run_all.sh                  # about 3 minutes; all results into results/
python figures/make_figs.py results figures
bash paper/build.sh                       # DOCX, and PDF if LibreOffice is installed
```

Checks: `run_all.sh` regenerates identical results (all splits and resamples use fixed seeds); `make_figs.py` regenerates the figures pixel for pixel; `paper/build.sh` produces the 16-page DOCX and PDF in `paper/build/`. Page count differs slightly between renderers: check the final PDF exported from Word.

The paper text lives in `paper/manuscript.md` (markers: `FIGURE:`, `TABLE:` with `WIDTHS:`/`SPLIT:`/`CAPTION:`, `EQUATION:`, `_{subscript}`, `*italic*`). The builder fills the official ECIS 2027 template, keeps its title-page author box, sets the header and blanks the document metadata for double-blind review. `paper/place_floats.py` searches figure and table positions that minimise empty space; `paper/manuscript_shortened_option.md` holds a pre-tested shortened text (about one page shorter) in case space is needed for the confirmatory table.

## Confirmatory evaluation (planned)

The design was developed and evaluated on the same 1,433 calls. The confirmatory evaluation tests the frozen design on calls that played no part in it. The full protocol and the predictions are in `confirmatory/PROTOCOL.md`; step-by-step instructions for running it are in `confirmatory/README.md`.

What will be run:
1. **Score** the SAFETY SENTRY train split (7,767 calls) and the Mailu out-of-distribution split (198 calls) with the same three models, and re-score 150 test-split calls to detect vendor model changes. `confirmatory/score_split.py` reproduces the original run exactly; it is resumable and costs about USD 2.50 in total.
2. **Analyse** with `confirmatory/confirm_analysis.py`, fixed before any new score exists:
   - Primary test: the three G4 policies calibrated on the 1,433 calls are applied, unchanged, to the untouched train calls.
   - The calibration procedure is repeated on disjoint calibration samples of the train split, a closer stand-in for separate deployments than resampled splits.
   - G5 is calibrated on the full train pool, which has enough refusals per service group.
   - The frozen gates are applied to the unseen Mailu service.
   - Every prediction in the protocol receives a verdict, and a table in the paper's format is written.

## Before sharing this repository

- For a double-blind review link, remove `docs/internal_reviews/`, and clear the notebook outputs (`jupyter nbconvert --clear-output --inplace notebooks/*.ipynb`). The outputs and Markdown exports contain local paths with a user name.
- The notebooks contain only a placeholder API key. Keep real keys in `.env`, which git ignores.
- The SAFETY SENTRY corpus is not redistributed here (see `data/README.md`).

## Environment

Python 3.10 or newer with the packages in `requirements.txt`. The figures use the Inter font if it is installed; LibreOffice is optional for the PDF export. Results in the paper were produced with numpy 2.5, pandas 3.0 and scipy 1.18.
